## Tema e Ideia do Projeto
* **Tema:** Conversor de unidades científico e económico
* **Ideia:** Desenvolver uma aplicação web interativa que permite aos utilizadores realizar conversões de unidades de medida e de moeda. A ferramenta será capaz de fazer: 
Conversão Económica (Moedas): Comunicação via HTTP com a API ExchangeRate-API para obter e aplicar taxas de câmbio atualizadas.
Conversão Científica (Unidades de Medida): Utilização de fórmulas matemáticas em JavaScript para converter grandezas físicas e científicas (como temperatura, comprimento e peso).
